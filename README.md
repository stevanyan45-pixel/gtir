# Գտիր.am — Հայաստանի բիզնեսների և ծառայությունների հարթակ

Աշխատող կայք. գրանցում, բիզնեսների ավելացում լուսանկարներով, որոնում և ֆիլտրեր,
բիզնեսների էջեր, կարծիքներ, ադմին վահանակ, հայտարարությունների հաստատում,
վճարովի փաթեթներ (Pro / Premium)։ Լեզուներ՝ հայերեն, ռուսերեն, անգլերեն։

Ամբողջը **անվճար** է. ոչ մի սերվեր կամ ամսավճար պետք չէ։

---

## Ինչից է բաղկացած

| Մաս | Ինչ է անում | Գինը |
|---|---|---|
| Կայքի ֆայլերը (այս թղթապանակը) | Էջերը, դիզայնը | — |
| **Supabase** | Բազա, գրանցում, լուսանկարներ | Անվճար (500MB բազա, 1GB նկարներ, 50 000 օգտատեր) |
| **Netlify** կամ **Cloudflare Pages** | Կայքը համացանցում | Անվճար |
| Դոմեն `gtir.am` | Սեփական հասցե | Վճարովի (կարելի է հետո) |

Մինչև Supabase-ը միացնելը կայքը աշխատում է **ԴԵՄՈ ռեժիմով**. ամեն ինչ աշխատում է,
բայց տվյալները պահվում են միայն քո բրաուզերում։ Դեմո ադմին՝ `admin@gtir.am` / `admin123`։

| Ֆայլ | Էջ |

| `index.html` | Գլխավոր. որոնում, քաղաք, կատեգորիաներ, հանրաճանաչ, նորեր, մասնագետներ |

| `add.html` | Բիզնեսի ավելացում / խմբագրում, լուսանկարների վերբեռնում |
| `login.html` | Մուտք և գրանցում |
| `account.html` | Իմ հայտարարությունները, կարգավիճակը, պրոֆիլը |
| `admin.html` | Ադմին. հաստատում/մերժում, փաթեթներ, հայտեր, օգտատերեր, վիճակագրություն |

Քաղաքներ և կատեգորիաներ՝ `js/data.js`։ Թարգմանություններ՝ `js/i18n.js`։

## Գործարկում (քայլ առ քայլ)

### Քայլ 1. Supabase (բազա)
1. Բացիր https://supabase.com → **Start your project** → գրանցվիր (կարելի է Google-ով)։
2. **New project** → անուն՝ `gtir`, Region՝ **Frankfurt (eu-central-1)**, գաղտնաբառ գրիր և պահիր։
3. Ձախ մենյու → **SQL Editor** → **New query** → պատճենիր `supabase/schema.sql` ֆայլի ամբողջ պարունակությունը → **Run**։
4. Ձախ մենյու → **Authentication** → **Sign In / Providers** → **Email** → անջատիր **Confirm email**
   (սկզբի համար. անվճար տարբերակը ժամում քիչ նամակ է ուղարկում)։
5. **Project Settings** → **API** → պատճենիր **Project URL** և **anon public** բանալին
   և տեղադրիր `js/config.js` ֆայլում.
   ```js
   SUPABASE_URL: "https://xxxx.supabase.co",
   SUPABASE_ANON_KEY: "eyJhbGciOi...",
   ```

### Քայլ 2. Կայքը համացանցում (Netlify)
1. Բացիր https://app.netlify.com → գրանցվիր։
2. **Add new site** → **Deploy manually** → քաշիր `gtir-am` թղթապանակը պատուհանի մեջ։
3. Մի քանի վայրկյանից կայքը պատրաստ է՝ `something.netlify.app` հասցեով։
   **Site settings → Change site name** → օրինակ՝ `gtir` → հասցեն կլինի `gtir.netlify.app`։

### Քայլ 3. Դառնալ ադմին
1. Կայքում գրանցվիր քո էլ. փոստով։
2. Supabase → **SQL Editor** → գրիր (քո էլ. փոստով) և **Run**.
   ```sql
   update public.profiles set role = 'admin' where email = 'քո@email.com';
   ```
3. Թարմացրու կայքը → մենյուում կհայտնվի **Ադմին**։

### Քայլ 4 (հետո). Դոմեն
Գնիր `gtir.am` (կամ լատինատառ տարբերակ) դոմենը .am գրանցողներից և Netlify-ում
**Domain management → Add domain**։

## Ինչպես է աշխատում բիզնես մոդելը
1. Բիզնեսն ավելացնում է հայտարարություն **անվճար** → ադմինը հաստատում է։
2. «Իմ էջը» → **Առաջ մղել** կամ «Գներ» էջ → ընտրում է Pro/Premium և ամիսները → հայտ։
3. Ադմինը տեսնում է հայտը «Փաթեթի հայտեր» բաժնում, ստանում վճարումը (Idram/Telcell/փոխանցում)
   և սեղմում **Ակտիվացնել** → բիզնեսը բարձրանում է որոնման մեջ և ստանում նշան։
4. Ժամկետն ավարտվելուց հետո փաթեթն ինքնաբերաբար վերադառնում է Անվճարի։

Գները փոխել՝ `js/config.js` → `PRICES`։

## Հետագա զարգացում
- Առցանց վճարում (Idram / Ameria vPOS) — `pricing.js`-ում հայտի փոխարեն։
- Գովազդային բաններներ գլխավոր էջում։
- Քարտեզ (Leaflet + OpenStreetMap, անվճար)։
- Կայքի ինդեքսավորում Google-ում (sitemap)։

## Անվտանգություն
- Բոլոր իրավունքները ստուգվում են բազայում (Row Level Security). սովորական
  օգտատերը չի կարող ինքն իրեն հաստատել, Premium դնել կամ ադմին դառնալ։
- `anon public` բանալին նախատեսված է բրաուզերի համար. **երբեք** կայքում մի դիր `service_role` բանալին։
